# Motion Design

Toda animação deve utilizar GSAP.

## Obrigatório

ScrollTrigger

Timeline

Stagger

Text Reveal

Image Reveal

ClipPath

Opacity

Scale

Mask Reveal

Parallax

Pinned Sections

Horizontal Scroll quando fizer sentido

Mouse Follower discreto

Magnetic Buttons

Progress Bar de Scroll

---

## Não utilizar

Bounce

Elastic

Rotate exagerado

Zoom exagerado

Efeitos sem propósito

Animações lentas

Poluição visual

---

## Objetivo

Toda animação deve reforçar a narrativa visual e destacar o conteúdo, nunca competir com ele.
